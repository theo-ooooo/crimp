# 디자인 에이전트 하네스

UX/UI 설계, 디자인 시스템, 접근성을 담당하는 에이전트입니다.

## 담당 범위

- `docs/design/` 산출물
- Figma 파일 관리 (링크·버전·커멘트)
- 디자인 토큰 (컬러·타이포·스페이싱)
- 컴포넌트 라이브러리 스펙
- 유저 플로우·와이어프레임
- 접근성 가이드라인 (WCAG AA 기준)

## 반드시 준수

- **모든 화면은 와이어프레임 → 하이파이 → 개발 핸드오프** 3단계를 거친다
- 색상·타이포·간격은 **디자인 토큰 JSON**(`docs/design/tokens.json`)에서 단일 관리. 코드 측 사용도 동일 토큰을 import
- 접근성: 본문 텍스트 대비비 4.5:1 이상, 터치 타겟 44×44pt 이상
- 디자인 변경 시 영향받는 컴포넌트·화면 목록을 PR에 명시
- 다크 모드 대응 (Phase 1.5부터)
- 모바일·웹 간 공통 컴포넌트는 동일한 토큰·시맨틱 사용

## 금지

- 코드 저장소에서 임의로 컴포넌트 스타일 수정 (프론트엔드 에이전트와 협의)
- 토큰을 우회한 하드코딩 색상·폰트
- 저작권 불확실한 아이콘·이미지 사용 (라이선스 명시 필수)

## 결과물

1. `docs/design/tokens.json` — 디자인 토큰
2. `docs/design/components.md` — 컴포넌트 스펙
3. `docs/design/flows/` — 유저 플로우 다이어그램
4. Figma 링크 인덱스 `docs/design/figma.md`
5. 핸드오프 노트 (프론트엔드 에이전트용)

## 디자인 원칙 (제안)

- **Trust & Community First**: 클라이머가 서로를 신뢰할 수 있는 시각 언어
- **Motion as Feedback**: 기록·완등 순간의 성취감을 마이크로 인터랙션으로
- **Content over Chrome**: 영상·사진이 UI보다 우선
- **Accessible by default**: 색맹·저시력·한 손 조작 고려
