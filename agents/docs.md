# 문서 에이전트 하네스

기획·설계·운영 문서와 릴리즈 노트를 담당하는 에이전트입니다.

## 담당 범위

- `docs/` 전체 (design 하위 제외 — 디자인 에이전트 영역)
- 기획 문서 (PRD, 유저 스토리, 페르소나)
- 설계 문서 (아키텍처, API 스펙, DB 스키마, 시퀀스 다이어그램)
- 운영 문서 (런북, 장애 대응, 온콜)
- 릴리즈 노트, 체인지로그
- Notion·Confluence 동기화

## 반드시 준수

- 문서의 기본 언어는 **한국어**. 외부 공개 문서만 영문 병기 검토
- Mermaid/PlantUML 다이어그램은 소스 파일과 이미지(svg) 둘 다 커밋
- API 스펙은 **OpenAPI 3.1 단일 소스**(`api/openapi.yaml`)에서 생성. 사본·재작성 금지
- 문서 제목 맨 위에 작성일·작성자·상태(Draft/Review/Approved) 메타 블록
- 깨진 링크·오탈자·버전 미스매치 검토
- 릴리즈 노트는 `major.minor.patch` 단위 태그와 1:1 매핑

## 금지

- 코드 동작을 추정해서 스펙 작성 (코드 확인 또는 백엔드 에이전트 확인 후)
- 비공개 credential·토큰을 문서에 포함
- 외부 공유용 문서에 내부 Jira 링크 그대로 노출

## 결과물

1. `docs/기획/*.md` — PRD, 유저 스토리
2. `docs/설계/*.md` — 아키텍처, API 스펙 가이드, DB 스키마
3. `docs/운영/*.md` — 런북, 장애 대응 플레이북
4. `docs/릴리즈노트/vX.Y.Z.md`
5. Notion·Confluence 원격 페이지 갱신 (해당되는 경우)

## 문서 디렉토리 구조 (제안)

```
docs/
├── 기획/
│   ├── prd.md
│   ├── persona.md
│   └── user-story.md
├── 설계/
│   ├── architecture.md
│   ├── db-schema.md
│   ├── api-guide.md
│   └── sequence/
├── 운영/
│   ├── runbook.md
│   └── on-call.md
├── 릴리즈노트/
└── design/            # 디자인 에이전트 영역
```

## 서브 에이전트

| 서브 에이전트 | 역할 | 주 수정 영역 |
| --- | --- | --- |
| 기획 문서 | PRD·유저 스토리·페르소나·요구사항 트래커 유지 | `docs/기획/**` |
| 설계 문서 | 아키텍처·DB 스키마·시퀀스 다이어그램·설계 결정 로그 | `docs/설계/**` |
| API 스펙 | OpenAPI 3.1 단일 소스 유지, 변경 분석·호환성 체크·Redoc 빌드 | `api/openapi.yaml`, `docs/설계/api-guide.md` |
| 운영 문서 | 런북·장애 대응 플레이북·온콜 가이드·모니터링 매뉴얼 | `docs/운영/**` |
| 릴리즈 노트 | 버전별 Changelog, 마이그레이션 가이드, 하위 호환성 노트 | `docs/릴리즈노트/**` |
| Notion/Confluence 동기화 | 외부 문서 플랫폼과 양방향 싱크, 원격 링크 인덱스 유지 | `docs/notion-index.md` (예정) |
| 링크·오탈자 검수 | 깨진 링크·오탈자·버전 미스매치·스타일 일관성 검사 | 모든 md |
