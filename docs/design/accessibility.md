# 접근성 가이드 (A11y)

WCAG 2.2 **AA** 기준. 한국어·영어 환경·저시력·한 손 조작까지 고려.

## 체크리스트

### 색·대비
- [ ] 본문 텍스트 대비비 **4.5:1** 이상 (AA)
- [ ] 큰 텍스트(18pt+) 대비비 **3:1** 이상
- [ ] 정보 전달을 색에만 의존하지 않는다 (아이콘·텍스트 병행)
- [ ] 색맹 시뮬레이션으로 Protanopia·Deuteranopia 검증

### 키보드·포커스
- [ ] 모든 인터랙션 요소가 Tab 순서에 포함된다
- [ ] 포커스 링은 모든 인터랙션 요소에서 **명확히 보인다**
- [ ] Escape / Enter / Space 키가 의도대로 동작한다
- [ ] 모달 열림 시 포커스 트랩

### 터치 타겟
- [ ] 터치 타겟 **44×44 pt** 이상 (iOS HIG / Material)
- [ ] 인접 터치 타겟 간 **8px** 이상 여백

### 스크린 리더
- [ ] 아이콘 버튼에 `aria-label` 필수
- [ ] 랜드마크(header / main / nav / footer) 명시
- [ ] 동적 콘텐츠는 `aria-live` 사용
- [ ] 이미지 대체 텍스트: 의미가 있는 이미지는 설명, 장식 이미지는 빈 문자열

### 모션·시각
- [ ] `prefers-reduced-motion` 존중 (애니메이션 축소·제거)
- [ ] 자동 재생 영상 기본 음소거, 3초 이상이면 정지 가능
- [ ] 깜빡임 3회/sec 이하

### 폼·피드백
- [ ] 필드 레이블은 항상 표시 (placeholder만 사용 금지)
- [ ] 에러는 색 + 아이콘 + 텍스트 3중 표시
- [ ] 성공·실패 피드백에 햅틱 동반 (앱)

### 한글·다국어
- [ ] 폰트 렌더링: Pretendard 우선, 시스템 폰트 폴백
- [ ] 줄바꿈: 한글 줄바꿈 규칙 준수 (word-break: keep-all 고려)
- [ ] RTL 대비는 Phase 3 이후

## 자동 검증

- 웹: `eslint-plugin-jsx-a11y`, Lighthouse a11y 점수 90+
- 앱: RN Accessibility Inspector 체크
- 디자인: Figma Plugin "Stark"로 대비비·컬러블라인드 검증

## 수동 QA

- 키보드만으로 주요 플로우 (로그인 → 피드 → 로그 기록) 수행 가능 여부
- VoiceOver (iOS) / TalkBack (Android) / NVDA (Windows) 낭독 적절성
- 화면 200% 확대 시 가로 스크롤·절단 없음
