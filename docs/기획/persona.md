## 1. 입문자 — 지수 (Phase 1 보조 타겟)

| 항목 | 내용 |
| --- | --- |
| 나이 | 25 |
| 직업 | 사무직 |
| 클라이밍 경력 | 1~3개월 |
| 주력 종목 | 실내 볼더링 |
| 빈도 | 주 1~2회 |

### 행동·동기

- 친구 따라 시작했고 재밌어서 자주 가고 싶음.
- 그레이드를 잘 모르고, 색깔만 보고 푼다.
- 인스타에서 다른 사람들 영상 보고 자극받는다.

### 페인 포인트

- 어떤 암장이 입문자에게 좋은지 모름.
- 자기 레벨이 어디쯤인지 가늠 안 됨.
- 같이 갈 사람이 없으면 혼자 가기 부담.

### Crimp 기대값

- 위치·난이도 분포 기반 암장 추천 (M3)
- 첫 등반 로그를 시각적으로 모아 보여주는 홈 (M4)
- (Phase 1.5) 크루/입문자 모임 발견

## 2. 중급자 — 현우 (Phase 1 **핵심 타겟**)

| 항목 | 내용 |
| --- | --- |
| 나이 | 30 |
| 직업 | 개발자 |
| 클라이밍 경력 | 1~2년 |
| 주력 종목 | 실내 볼더링 + 가끔 리드 |
| 그레이드 | V4 ~ V6 |
| 빈도 | 주 2~3회 |

### 행동·동기

- 자기 그레이드를 끌어올리는 데 강한 동기.
- 영상 찍고 자세 분석하는 것을 즐김.
- 인스타에 완등 영상을 올리지만 정작 본인 기록은 흩어져 있음.

### 페인 포인트

- 엑셀/메모장으로 기록하다가 그만둠.
- 다른 암장의 그레이드와 비교 어려움.
- 아웃도어 시작하고 싶은데 정보·파트너 부재.

### Crimp 기대값

- 세션·시도 단위 로그 + 그레이드 추적 (M4)
- 피드에서 동급 클라이머 영상·tip (M5/M6)
- (Phase 1.5) 영상 타임라인, 프로젝트 트래킹
- (Phase 2) 아웃도어 시즌·파트너

**Phase 1 MVP 의 must-have 는 이 페르소나의 페인 포인트 해결을 1순위로 한다.**

## 3. 고급자 — 민지 (Phase 2 타겟)

| 항목 | 내용 |
| --- | --- |
| 나이 | 28 |
| 직업 | 프리랜서 |
| 클라이밍 경력 | 5년 |
| 주력 종목 | 리드 + 아웃도어 |
| 그레이드 | 5.12a / V7 |
| 빈도 | 주 3~4회 |

### 행동·동기

- 프로젝트 (특정 문제·루트) 를 몇 주~몇 달 단위로 트래킹.
- 비레이 파트너 신뢰성 검증 후 동행.
- 해외 정보 (Mountain Project, 유튜브) 적극 활용.

### 페인 포인트

- 프로젝트 진행 상황을 시각화할 도구 부재.
- 새 비레이 파트너의 안전 의식·실력 검증 어려움.
- 한국어 아웃도어 정보 부족.

### Crimp 기대값 (대부분 Phase 2)

- 프로젝트 트래킹 (M4 의 확장)
- 파트너 매칭 + 안전 평가 시스템
- 자연 암장 가이드·시즌·날씨

**Phase 1 에서는 핵심 페르소나가 아니지만, 베타 사용자로 모셔서 그레이드/로그 정확도 피드백을 받는다.**
