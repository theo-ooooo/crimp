## 1. 한 줄 정의

> **한 번의 세션, 한 번의 시도를 놓치지 않고 움켜쥐는 클라이머의 디지털 홈.**

`crimp` (크림프) — 작은 홀드를 꽉 움켜쥐는 클라이밍 동작. 모든 등반 순간을 놓치지 않고 잡는다는 의미.

## 2. 문제 정의

국내 클라이밍 인구가 빠르게 늘고 있지만, 클라이머의 **기록·정보·연결**이 인스타·카톡·블로그·구전으로 파편화되어 있다.

| 문제 | 현 상태 | 영향 |
| --- | --- | --- |
| 정보 파편화 | 암장별 세팅·그레이드·세션이 인스타·카톡방에 분산 | 정보 탐색 비용↑, 휘발 |
| 기록 부재 | 등반 로그를 엑셀·메모장·DM 으로 개인 관리 | 진척도 추적 불가, 동기 저하 |
| 파트너 매칭 어려움 | 리드/아웃도어 파트너 찾으려면 오픈채팅 전전 | 진입 장벽↑, 안전 이슈 |
| 그레이드 카오스 | 색상·V-scale·Font·암장별 스케일 혼재 | 본인 레벨 추정 불가 |
| 아웃도어 접근성 | 자연 암장 정보가 블로그·책·구전 의존 | 신규 클라이머 외부 진출 어려움 |

## 3. 비전 & 미션

- **비전**: 모든 클라이머가 자신의 등반 여정을 기록하고, 동료를 만나고, 성장하는 디지털 홈.
- **미션**:
  1. 디지털 클라이밍 로그 (개인 진척도 트래킹)
  2. 실내 → 아웃도어 성장 경로 지원 (Phase 2+)
  3. 암장·브랜드·크루 생태계 연결

## 4. 타겟 사용자

**Phase 1 종목은 실내 볼더링 단일** (리드·아웃도어는 Phase 2+). 그레이드 체계도 V-scale + 색상 위주로 단순화.

상세는 [persona.md](./persona.md) 참조. 요약:

| 페르소나 | 특징 | 주요 니즈 | Phase 1 |
| --- | --- | --- | --- |
| 입문자 **지수** (25, 1~3개월) | 실내 볼더링 시작 | 내 레벨 가늠, 암장 추천 | 보조 |
| 중급자 **현우** (30, 1~2년차, V4~V6) | 실내 볼더링 꾸준 | 기록 트래킹, 동기부여 | **핵심** |
| 고급자 **민지** (28, 5년차) | 리드/아웃도어 | 프로젝트·파트너 | Phase 2 |

**Phase 1 핵심 타겟: 중급자 "현우"** — 실내 볼더링 기록 트래킹 니즈가 가장 강하고, 친구 추천을 통해 입문자를 끌어올 수 있다.

## 5. 차별화 (Phase 1 — "왜 Crimp 인가")

기존 클라이밍/운동 앱과의 명확한 구분점. **MVP 한 사용자 만남 안에서 즉시 체감되는 4 가지**:

| 항목 | 기존 (인스타·메모장·헬스앱·Climbingfan 등) | Crimp Phase 1 |
| --- | --- | --- |
| **1. 시도 단위 로그** | 카운터·텍스트 메모 | SEND/FLASH/ONSIGHT/TRY/FAIL × 그레이드 × 홀드 색 — 한 시도 = 한 데이터 포인트 |
| **2. 그레이드 진척도** | 본인이 엑셀로 추적 | 자동 집계 — 이번 주 완등 / 누적 / 최고 그레이드 한눈에 |
| **3. 자동 피드 게시** | 인스타에 별도로 올림 | 시도 결과 SEND 면 자동으로 친구 피드에 노출 (off 토글 1.5+) |
| **4. 암장 컨텍스트** | 매번 인스타·블로그 검색 | 암장 별 세팅 주기 / 활성 루트 / "내 암장" 1탭 |

후속 단계 차별점 (Phase 1.5/2): 크루·파트너 매칭, 영상 타임라인, 아웃도어 가이드.

### 6.2 Nice-to-have (Phase 1.5 — 핵심 차별점 확장)

- **크루 개설/가입** (지역·수준·스타일별) — 차별화 §5 Phase 2 항목 가져옴
- **파트너 매칭 베타** (날짜·암장·레벨)
- **친구/팔로우** (현재 friends 탭 빈 상태 → 채움)
- **영상 타임라인 주석**
- **BottomTabs 정식** (web — 현재 entry card 임시)
- **그레이드 컨센서스 투표**

### 6.3 Out of scope (Phase 2+)

- 리드 / 자연 암장 / 아웃도어 가이드 (Phase 1 종목은 실내 볼더링 단일)
- 이벤트 티켓팅·결제
- AI 루트/자세 분석
- 장비 커머스
- 프리미엄 멤버십

## 9. 기술 스택

확정. 상세는 [docs/설계/architecture.md](../설계/architecture.md) 참조.

```
Backend  : Java 21 / Spring Boot 3.x / JPA / MySQL 8.x / Redis 7
Mobile   : React Native (iOS/Android) / TypeScript / TanStack Query / Zustand
Web      : Next.js 14 / TypeScript / TanStack Query
Infra    : AWS (ECS Fargate, RDS, S3, CloudFront, MediaConvert)
Auth     : OAuth2 (Kakao / Apple / Google) + JWT (15m/14d, refresh 회전)
CI/CD    : GitHub Actions
모니터링 : Grafana + Loki + Prometheus (또는 Datadog)
```

## 10. 수익 모델 (Phase 2+)
