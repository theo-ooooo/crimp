## 과거 메모 (요약)
- PR #115 디버깅 사이클에서 사용자가 PR03 (Fly proxy no healthy instances) 마주침. 진짜
  원인은 JVM cold-start 4분 27초 (shared-cpu-1x throttled). always-on + cpu-2x +
  grace 5m 으로 fly.toml 조정.
- iOS 17 의 multi-cam virtual device 가 `useCameraDevice('back')` 의 기본값으로 자동
  선택 안 돼 0.5x 가 안 잡혔던 회귀: `physicalDevices: ['ultra-wide-angle-camera',
  'wide-angle-camera', 'telephoto-camera']` 명시.
- 카메라 zoom 좌표계: vision-camera 의 multi-cam virtual device 는 ultrawide 를 1.0
  으로, wide(neutral) 을 약 2.0 으로 잡음. 사용자 친화 0.5×/1×/2×/3× 라벨은 device-zoom
  = userZoom × neutralZoom 변환 + min/max 클램프.
